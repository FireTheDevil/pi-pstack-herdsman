# Validation boundaries

Local command tests exercise the actual extension handlers using a mock Pi context. They cover mode default/enable/disable, queueing, active-branch restore, catalog independence, child identity suppression, automatic global profile copying on lead session load, preservation of existing global files, symlink refusal, and project-only preview/confirmation/cancellation/headless command behavior. Tests redirect the agent directory to temporary project fixtures; they do not modify the user's global directory.

Definition tests check the shipped leaf template contract, extension-discovery flag, native tool allowlists and materialized project paths. The allowlists do not sandbox loaded extension handlers. These tests are not a reimplementation or runtime test of Herdsman's full YAML discovery/overlay engine. Documentation contract checks confirm global-over-project precedence, malformed-definition failure and exclusion precedence against the installed 0.19.1 docs.

Host loader, API, and documentation compatibility was checked against Pi 1.0.2 and pi-herdsman 0.19.1. Live delegation attempts with both shell verifier profiles and the read-only investigator failed with `Tool fabric_exec not found`. The cause of this tool-route failure is not established. These checks do not prove working live delegation or complete fleet compatibility.

The host check uses the installed Pi loader and skill loader in a repository-local disposable cwd, without starting a session, inference or launching an agent. It does not copy global profiles or establish live Herdr connectivity, agent discovery/override behavior, model availability, effective provider tool presentation, or live child suppression. These remain runtime-validation limits for a later authorized environment test.

The resource validator checks all 50 hidden skills, 23 playbooks, links, forbidden old backend operations, standalone imports and complete immediate-source/destination hashes. Historical lineage is preserved. The reviewed Cursor delta targets 0.15.9 at e43c7ee26e0038c6c1fa8380dd34ce86ff94cb2a; new resources and adapted bodies record pinned source hashes. The supplied checkout HEAD was checked locally, not remotely. `package.json.files` declares exact shipped file paths. Updater and validator share path safety, resource completeness, and generated membership checks in `scripts/manifest.mjs`. Neither consults Git. Normal refresh preserves source hashes, lineage, reviewed adaptations, and metadata history. Removed checkout-only generated records remain in `generatedHistory`, outside current membership. Unrelated configuration is neither hashed nor shipped. The package inventory tests run `npm pack --ignore-scripts`, compare actual tar members with the declaration, and check extracted packages outside Git and inside an unrelated checkout with Git unavailable.

Selected additions are benchmark-checklist, principle-explain-the-number, and correct. Each gates execution on assignment authority and available tools, with read-only evidence assessment and explicit gaps. make-bot-ui remains excluded by user selection and unavailable Cursor routine, connector, and secret-request capabilities. Plan checks exercise the actual CLI with a valid hourly scheduler-gated skeleton and reject missing cadence, scheduler authority, and stored objective. Skill case walkthroughs are prose assessments, not model trials.

Queued watching supports `--stop-at-frontier-ready`, only with `--queued-stack` and without `--status-only`. It returns the existing nonterminal `WAITING` / `merge-queue` receipt once and exits 0 without merging. Default queued mode still waits until all captured PRs merge. The bounded launcher checks dependency versions and the installation key before importing the CLI, without installing or restarting. Watcher tests use existing Commander 14.0.0 in disposable fixtures. Real executable tests use a local fixture `gh`, await process exit, verify no merge command, and confirm watcher and fixture process cleanup. They cover an unmerged clean frontier with pending upstack checks, default completion after external fixture merges, invalid flags, and missing or stale dependencies.

These process tests do not prove installed Herdsman settlement or live forge behavior. No independent review or live delegation smoke test is part of this implementation assignment.
