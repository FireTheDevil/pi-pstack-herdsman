### Autopilot-stack

Run [Autopilot-full](autopilot-full.md), but do not merge. Its unattended trust preflight, bounded owner handoffs, lead-owned reviews, tool ceilings, explicit leases, verification cadence, countersigns, recovery and operator gates still apply. After each implementation handoff, the lead orchestrates no-comments, interrogate, trail review and watcher delegation with explicit skill and execution evidence. Leaves do not launch reviewers or watchers.

1. **Stop at verified instead of step 5's merge.** Hand each PR to the operator only when it is verified and green at its current head. Nobody merges, closes it or arms auto-merge. After handoff, nobody pushes without the operator's go. Every authorized scheduler tick names this file so the no-merge rule survives context changes. Without an authorized scheduler, report periodic auditing blocked.
2. **Stack only real dependencies.** Independent PRs branch from trunk. A PR that builds on another PR branches from and targets that parent's branch, per [Opening a PR](opening-a-pr.md). Its owner rebases onto the parent's exact tip instead of trunk. The root PR rebases onto trunk. Give each branch one writer and serialize topology operations across a chain. Pause affected owner writes before a restack and complete an explicit tip and lease handoff before resuming.
3. **Restack and recheck.** When a lower head changes, restack the PRs above it in dependency order. Use Autopilot-full's remote ownership check and exact SHA lease for rewritten pushes. An unchanged stable patch-id retains only the code verdict permitted by [Shipping](shipping.md). A changed patch follows Autopilot-full step 4. Every new head still needs current-head CI and mergeability. Apply merge-result and caller/dependency drift checks to each link before handoff. Nothing enters the verified handoff with missing evidence.
4. **Freeze the delivered PRs.** The operator owns landing. Once it starts, preserve Shipping's frozen topology and sanctioned immediate-child move. A mid-landing fix or other branch write waits for the operator's go.

Use this playbook when the operator lands the PRs, whether the queue is independent or dependent. Use Autopilot-full only when merge authority is granted.
